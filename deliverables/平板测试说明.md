# 平板测试方法

已经创建好一个常驻虚拟设备：`Tablet_pad`（Medium Tablet，2560×1600，320dpi，Android 16 / API 36）。

1. 在 Android Studio 打开当前 assignment2 项目。
2. 打开 `View → Tool Windows → Device Manager`，找到 `Tablet_pad`，点击启动按钮。
3. 在顶部运行设备下拉框，把 `Medium Phone` 切换成 `Tablet_pad`；运行配置保持 `app`。
4. 点击绿色 Run，等待安装并打开应用。如果设备列表没立即刷新，重新打开 Device Manager 或重启 Android Studio。
5. 首页应为左侧介绍、右侧水果列表。上下滚动，确认 6 种水果都能点击。
6. 打开西瓜等详情，应为左图右文字；图片尺寸比手机更大；字母正确。
7. 点击 Hear pronunciation，听英文。切成中文后点击“听发音”，听普通话。
8. 在中文详情页返回首页，确认首页仍是中文；关闭重开确认语言保留。
9. 测试横屏/竖屏，并确保可以滚动看到详情页的按钮。

只放大手机模拟器窗口不等于测试平板；需要选择真正的平板 AVD，才能验证 `layout-sw600dp`。

听不到声音时：先检查电脑及模拟器的媒体音量（模拟器侧边音量键），不要只调铃声音量。这里是 App 自带音频，不需要另装语音引擎，也不需要网络。

要比较手机：再选择 `Medium Phone` 运行。手机是纵向界面，平板是双栏。录屏展示两种设备以及中英文发音按钮。
