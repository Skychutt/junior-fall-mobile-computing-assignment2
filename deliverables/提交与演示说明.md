# 提交与演示说明

**正式作业视频尚未由学生录制。** `archive/early-demo/` 中的旧视频是此前开发过程中生成的历史演示，不属于学生录制的作业视频，也不适合提交。

## 当前文件

- `assignment2-source.zip`：最新源码和说明，解压后用 Android Studio 打开。排除 Git、缓存、构建目录、本机 SDK 配置、历史视频及 deliverables，避免嵌套打包。
- `fruit-garden-debug.apk`：当前版本调试 APK。
- `screenshots/`：开发期间的界面截图；以当前 APK 的实际运行界面为准。
- `录屏脚本与检查清单.md`：正式视频的准备和操作顺序。

`app/src/main/res/raw` 中是水果名称的合成发音，供应用播放，不是学生录制的旁白。

## 需要由学生完成

1. 阅读代码并练习解释 ListView/ArrayAdapter、Intent、水果 ID、本地化和资源限定符。
2. 录制手机和平板、中英文首页及详情、发音和代码讲解。
3. 文件对视频时长有 1–2 分钟与 1 分钟以内两种表述，先准备约 60 秒版本，最新教师/Moodle 要求优先。
4. 回放确认画面、字幕或旁白清楚；按课程要求提交 ZIP 和视频，并准备现场演示。

GitHub 备份不等于 Moodle 提交。尚未自动提交任何作业。
