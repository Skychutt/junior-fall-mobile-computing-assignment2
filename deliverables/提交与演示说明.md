# 提交与演示说明

## 文件

- `assignment2-source.zip`：源码，解压后用 Android Studio 打开。
- `fruit-garden-debug.apk`：可安装的调试 APK。
- `fruit-garden-demo.mp4`：手机与平板的实际操作录屏，含代码思路字幕，少于一分钟。
- `screenshots/`：手机、平板的英文与中文界面截图。

## 演示时说明

1. 首页用 ListView 和 ArrayAdapter 生成水果图片列表。
2. 点击条目后，Intent 传递固定 fruit_id，详情 Activity 查找水果并显示名字、图片、英文字母。
3. `values` 与 `values-zh` 保存两种语言。按钮保存语言选择并重建页面。
4. `layout-sw600dp` 为平板选择不同的布局，`values-sw600dp` 改变图片显示尺寸。
5. `drawable-mdpi` 和 `drawable-xhdpi` 提供不同像素尺寸的图片。

录屏是实际运行演示；请先理解代码，再进行课程要求的现场答辩。尚未向 Moodle 上传或提交任何文件。
